# Producto

## Qué estamos construyendo

Una plataforma para crear y administrar sitios web profesionales para distintos clientes. El primer template es **Visual Portfolio**, orientado a estudios de arquitectura, fotografía, arte y otras prácticas visuales. El primer cliente es **Viola-Di Benedetto**, con contenido en español e inglés.

El sistema separa el contenido de la presentación:

- El equipo de software define templates, componentes, navegación y reglas visuales.
- El cliente carga y administra contenido estructurado desde un panel.
- El mismo contenido debe poder reutilizarse en más de una presentación futura.

## Alcance del MVP

El sitio público debe cubrir Home, Proyectos, Concursos, Viajes, Publicaciones, Estudio y Contacto. Debe ser visual, rápido, accesible, responsive y preparado para galerías con muchas imágenes y algunos videos.

El panel debe permitir iniciar sesión, editar datos del negocio, crear y ordenar entradas, administrar multimedia, publicar/despublicar, destacar contenido, administrar personas y editar contacto.

El contenido inicial contempla títulos, slugs, descripciones, ubicación, fechas, links, galerías, publicaciones, staff, colaboradores y CVs.

## Qué no estamos construyendo

- Un page builder o sistema drag-and-drop.
- Libertad para elegir tipografías, colores, márgenes o CSS.
- Un dashboard visible en el sitio público.
- Una plataforma SaaS multi-tenant completa en esta etapa.
- Traducción automática, GraphQL, microservicios o un backend separado.

## Dirección visual

Las referencias existentes muestran navegación discreta, composición editorial, galerías densas y protagonismo de la fotografía. El nuevo template debe conservar esa filosofía, mejorar mobile, accesibilidad, SEO y performance, y evitar gradients llamativos, glassmorphism, cards genéricas y animaciones decorativas.

## Decisiones abiertas para la siguiente etapa

Definir el contenido real de Viola-Di Benedetto, las variantes exactas de galería, el flujo de subida y transformación de imágenes, el proveedor de email del formulario de contacto y el alcance de los videos.
